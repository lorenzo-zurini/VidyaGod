# Functions that cannot meaningfully be a command, each with its reason (tools/cli_coverage/cli_coverage.py).
# One per line:   <qualified name, an fnmatch pattern, {constructor} or {destructor}>   # <why it is not a command>
# A pattern that matches nothing fails the check: keep this list exact.

# ---- object lifetime: reached by every command that brings the object up or down ----
{constructor}                # a constructor: runs when a command brings its object up (the model, the windows, a dialog)
{destructor}                 # a destructor: runs when its owner goes

# ---- Qt's own callbacks: Qt calls them; what they do is seen with `ui tree` / `ui screenshot`, caused with `ui …` ----
*::resizeEvent               # Qt resize handler: layout follows the window; seen in `ui tree`
*::showEvent                 # Qt show handler: runs when `ui tab` / a command shows the widget
*::hideEvent                 # Qt hide handler: runs when a widget is hidden
*::closeEvent                # Qt close handler: runs when a window is closed (`ui press`, quitting)
*::changeEvent               # Qt change handler (minimise, style, language): Qt calls it on a window-state change
*::keyPressEvent             # Qt key handler: the keys it handles are the actions `ui …` takes directly
*::keyReleaseEvent           # Qt key handler: as keyPressEvent
*::mousePressEvent           # Qt mouse handler: the clicks it handles are `ui click` / `ui card` / `ui cell`
*::mouseReleaseEvent         # Qt mouse handler: as mousePressEvent
*::mouseDoubleClickEvent     # Qt mouse handler: as mousePressEvent (`ui cell --activate`)
*::mouseMoveEvent            # Qt hover/drag handler: hover is cosmetic; drags are their own commands
*::wheelEvent                # Qt wheel handler: scrolling a view changes nothing `ui tree` reports
*::leaveEvent                # Qt hover handler: cosmetic
*::focusInEvent              # Qt focus handler: focus follows the actions `ui …` takes
*::focusOutEvent             # Qt focus handler: as focusInEvent
*::dragEnterEvent            # Qt drag-and-drop handler: what a drop does is its own command
*::dropEvent                 # Qt drag-and-drop handler: as dragEnterEvent
*::viewportEvent             # Qt viewport dispatcher: forwards to the handlers above
*::scrollContentsBy          # Qt scroll callback: scrolling changes nothing `ui tree` reports
*::eventFilter               # Qt event filter: intercepts the events above for another object
*::event                     # Qt event dispatcher: forwards to the handlers above


# ---- the CLI itself: every command runs through it, so each of these runs on every invocation ----
Command::*                   # the command registry and argument readers: what every command is declared and parsed with
CliApp::*                    # the CLI front end (parse, help, render, exit codes): it is what runs a command
CmdUtil::*                   # helpers the commands share (naming a package, a node, a list): run by the commands that call them
CommandServer::*             # the live socket: every command sent to a running app passes through it

# ---- what Q_OBJECT expands to: moc's meta-object plumbing, not behaviour of the class ----
*::metaObject                # Q_OBJECT: Qt's runtime type info
*::qt_metacall               # Q_OBJECT: moc's dispatcher (signals and slots are counted themselves)
*::qt_metacast               # Q_OBJECT: Qt's checked cast
*::qt_create_metaobjectdata  # Q_OBJECT: moc's meta-object builder
*::tr                        # Q_OBJECT: the translation lookup (no translations ship)
Platform::AcquireSingleInstanceLock  # the one-app-per-data-dir lock: taken by the app at start and by every command run here (CliApp)
Diagnostics::Note            # what Log() calls on every line; the tally it builds is `app diagnostics`

# ---- the node's plumbing: what every call into it does, not a thing to do ----
VidyaGodIPFS::VgFree         # frees each string the node hands back: runs after every call that returns one
VidyaGodIPFS::VgNet*         # the network-queue slot every fetch holds while it runs (DownloadSlot / ForegroundHold): `ipfs fetch`
IpfsWrapper::Set*Callback    # installs the app's receiver for the node's events at start (IpfsManager, FriendsManager); what arrives is `events`
IpfsWrapper::Set*Hook        # a test seam: unit tests put a fake network in place of the node with it
